# Nexus Game Devs privacy policies

Public privacy policies for our games, served by GitHub Pages at
https://nexusgamedevs.github.io/privacy/.

| Game | Page |
|---|---|
| Zodiac Match | https://nexusgamedevs.github.io/privacy/zodiac-match/ |

The source of each policy lives with its game (for Zodiac Match: `docs/privacy-policy.md`
in NexusGameDevs/ZodiacMatch). Update both together, and change the "Last updated" date,
before a release that changes what a game does with data.
